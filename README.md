# Huyendo-del-profesor-202205302
El juego Huyendo del Profesor trata sobre correr de el ya que el profesor lo quiere castigar y el estudiante tiene que esconderse en los salones donde cada solón es un nivel que tiene que pasar y si no lo pasa el profesor entra por el, perdiendo así una vida y tiene que volver a la entrada, tiene que llegar hasta la final sin ser atrapado por el M.
